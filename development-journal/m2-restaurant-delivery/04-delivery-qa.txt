6. VIVA QUESTIONS & ANSWERS
Q1: Why is validating against null specifically important when checking optional boolean fields?
A1: In JavaScript, typeof null is 'object'. If a validator checks `data.isAvailable !== null` before verifying
    typeof boolean, passing null skips the check and allows invalid data to pass into storage.
Q2: What is the benefit of splitting tests across distinct functional files (validation, auth, persistence)?
A2: It provides clear separation of concerns, simplifies defect root-cause analysis, and allows independent
    review of security, data integrity, and API contract compliance.
Q3: How does the smoke test differ from unit/integration tests?
A3: Unit/integration tests use mock servers and temporary directories. The smoke test runs against a live
    deployed or local development instance over real network sockets to verify end-to-end integration.
Q4: Why is attempting to toggle availability blocked when an active order is present?
A4: To maintain data consistency. A delivery partner cannot be in the available pool for dispatching while
    actively delivering another customer's order.
